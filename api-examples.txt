PUT /approval/{transactionId}/act
Request (ACCEPT):
{
  "checkerId": "2",
  "action": "ACCEPT",
  "remarks": "All checks passed"
}

Response (ACCEPT - approval+debit+complete succeed):
{
  "success": true,
  "message": "Transaction 1 accepted by checker 2",
  "data": {
    "id": 1,
    "status": "COMPLETED",
    "approvedBy": "2",
    ...
  }
}

Response (ACCEPT - validation fails):
Auto-rejects. Status becomes "REJECTED" with rejectionReason like "Maker (user ID 1) is not ACTIVE"
